# 💻 Tudão

## 📌 Sobre o projeto

O **Tudão** reúne atividades desenvolvidas durante meus estudos em programação e desenvolvimento de sistemas.

O objetivo é centralizar projetos, exercícios e aplicações práticas, mantendo uma estrutura organizada para acompanhar minha evolução como desenvolvedor.

## 🚀 Como utilizar

Clone o repositório:

```bash
git clone https://github.com/alison2521190431002-star/tudao.git
```

Entre na pasta:

```bash
cd tudao
```

Depois, escolha a atividade ou projeto que deseja executar.

Cada pasta pode possuir suas próprias instruções de instalação e execução.
